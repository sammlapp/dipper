Linux installation

Ubuntu, Debian, Linux Mint, Pop!_OS: download the .deb, then sudo apt install ./Dipper_*.deb

Fedora, RHEL, openSUSE: download the .rpm, then sudo dnf install ./Dipper-*.rpm (openSUSE: sudo zypper install ./Dipper-*.rpm)

Other distributions, or no admin rights: download the AppImage, run chmod +x Dipper_*.AppImage, then run it.

The .deb and .rpm use your system's own libraries and are the most reliable choice. The AppImage bundles its own, and on very new distributions (such as Ubuntu 26.04) its window can stay blank; use the .deb or .rpm there.

About Dipper

Dipper is an open-source desktop application for bioacoustics machine learning workflows.

Annotation

Binary, multi-class, and bounding-box annotation of audio clips with spectrogram visualization.

Inference

Run trained models over large audio datasets and review detections in the built-in reviewer.
